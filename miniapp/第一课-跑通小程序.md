# 第一课：在微信里记下一笔心情

这一课的目标是：导入项目 → 编译 → 保存一条虚构心情 → 重新打开后还看得到。真实 AppID 和权限准备好后，再用手机扫码预览。它是第一课工程，不是已完成的网站迁移版。

## 分工

你负责：安装微信开发者工具、用自己的微信扫码登录、注册/选择自己的小程序账号、填写 AppID、手机扫码、实际体验与反馈。我负责：项目结构、代码实现、讲解、代码检查和根据报错修复。终端中涉及本项目的检查命令也可以由我运行。

## 第一步：安装和登录

1. 打开微信开发者工具官方下载页：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
2. 当前电脑为 Windows，选择适合电脑架构的稳定版安装包；通常为 Windows 64 位。
3. 安装后打开“微信开发者工具”，用你自己的微信扫码登录。

本机检查时已有 Node.js；无需再次安装。第一课不需要购买服务器、域名或开通云开发。

## 第二步：理解账号和 AppID

微信账号是用来扫码登录的个人身份；小程序账号是你在微信公众平台注册并管理的应用；AppID 是这个小程序的标识；项目目录是电脑上的代码。它们不是同一个东西。

有正式小程序账号：登录 https://mp.weixin.qq.com/ ，在开发管理/开发设置等对应入口找到 AppID（菜单名称以实际后台为准）。用有该小程序开发权限的微信登录工具。

没有账号：先在开发者工具使用当前版本提供的测试号或无 AppID 模式，学习模拟器编译；随后到公众平台注册“小程序”，按自己的真实情况填写主体和管理员资料。测试模式能力以工具实际提示为准，不能保证支持正式账号的预览、云服务或上传能力。

本工程 `project.config.json` 的 `appid` 暂为 `touristappid`，这是学习占位，不是你的正式账号，也不具备发布资格。已有 AppID 时，通过导入界面或配置文件替换它。AppID 不等同于 AppSecret；这一步只需要 AppID，不需要把 AppSecret、上传私钥等发到聊天里。

## 第三步：导入已经准备好的工程

在开发者工具里选择“小程序 → 导入项目”（若当前版本用加号入口，进入后选择导入已有项目）。

| 字段 | 填写内容 |
| --- | --- |
| 项目名称 | 慢慢来 |
| 项目目录 | `C:\Users\17534\OneDrive\文档\ChatGPT\留学生情绪健康观察app\miniapp` |
| AppID | 你自己的小程序 AppID，或按工具提供的测试模式进入 |
| 项目类型 | 小程序 |
| 云服务/后端选项 | 若有此选项，本课选择不使用云服务 |

选包含 `project.config.json` 的 `miniapp` 目录，不是仓库根目录，不是 `web`，也不是内层 `miniprogram`。导入现有代码，无需再生成空白模板。

然后点击顶部“编译”。预期在模拟器中看到“慢慢来”、一条小事、“记一笔此刻的心情”和“看看心情足迹”。本课不运行 `npm run dev`，也不用启动网页服务器。

工具内置 TypeScript 编译由 `useCompilerPlugins: ["typescript"]` 启用。npm 依赖仅用于本机类型检查和自动化验证，本课不需要点击“构建 npm”。

## 第四步：亲手走完一次流程

使用虚构文字，例如“今天在学习写小程序”：

1. 首页点“换一个小灵感”，确认内容变化。
2. 点“记一笔此刻的心情”，选一个心情，输入练习文字。
3. 先点“先回去”，再次进入记录页，确认草稿恢复。
4. 点“轻轻记下来”，看到保存成功，再点“看看这笔足迹”。
5. 重新编译或正常关闭再打开，确认记录仍在。不要选择“清除缓存/数据”。
6. 删除这条测试记录，先取消一次，再确认一次，观察区别。

成功标准：不是只有页面能打开，而是写入、读取、恢复、删除都可验证。模拟器的存储和手机上的存储独立；手机看不到模拟器记录是正常现象。

## 第五步：用手机预览

正式 AppID、开发者权限和工具编译都准备好后，点击工具里的“预览”，用有权限的手机微信扫码。若提示无权限，应核对 AppID 对应账号的开发成员，而不是随便更换 AppID 或关闭安全检查。

手机预览是把当前开发代码放到微信里体验，不等于公开发布。后续“上传 → 后台设体验版 → 提交审核 → 正式发布”是不同阶段。

## 这一课只需要理解的代码

以 `miniprogram/pages/today/` 为例：

- `index.wxml`：摆放文字和按钮，`{{greeting}}` 表示显示页面数据。
- `index.wxss`：这个页面的样式，例如字号和间距。
- `index.ts`：页面逻辑，`bindtap="changeIdea"` 对应 `changeIdea()` 函数。
- `index.json`：页面配置，例如顶部标题。

全局部分：

- `app.json`：登记页面列表，第一个页面是默认首页。
- `app.wxss`：各页面共用样式。
- `app.ts`：小程序启动入口。
- `services/records.ts`：统一处理本地数据的读取、保存、校验和删除。
- `content/ideas.ts`：从现有网站复用的 24 条小事内容。

一个关键机制：`this.setData({ greeting: '你好' })` 更新数据后，WXML 中的 `{{greeting}}` 就会跟着变；直接给普通变量赋值不等于通知页面刷新。

本课练习：把 `pages/today/index.wxml` 中“你不是一个人”换成一句你喜欢的话，保存后点编译，观察变化；再把 `pages/today/index.wxss` 中 `.idea-title` 的 `font-size` 从 `44rpx` 改为 `40rpx`。每次只改一处，看清变化再继续。`rpx` 是小程序按屏幕宽度换算的尺寸单位。

## 数据到底存在哪里

调用 `wx.setStorageSync` 把内容写到当前设备的小程序本地存储，调用 `wx.getStorageSync` 读取。没有上传服务器，没有云备份，也不会自动读取网站记录。现在也没有微信账户间缓存隔离设计，应使用个人设备和虚构记录学习。

心情先写本机，只有写入成功才显示成功；草稿单独保存；重复提交同一笔不会新增重复记录；旧记录格式异常时阻止覆盖；日期保存记录发生时的当地日期。第一课没有完成云同步、导出备份或完整迁移，暂不建议用它保存唯一一份重要日记。

## 常见卡点

| 现象 | 先检查 |
| --- | --- |
| 找不到 app.json | 是否导入了含 project.config.json 的 miniapp 目录 |
| 提示 AppID 无效或权限不足 | 测试模式是否被工具支持；真实 AppID 是否填对；扫码微信是否有开发权限 |
| TypeScript 未编译 | 是否使用当前稳定版、配置是否保留 typescript 编译插件；提供首条具体报错 |
| 页面白屏 | 打开工具“调试器 → Console”，复制第一条红色报错和文件/行号 |
| 手机没有模拟器里的记录 | 本课本地存储本来不跨设备同步 |
| 修改后无变化 | 确认改的是 miniapp 内文件，保存后重新编译 |

给我反馈时说明做到哪一步、看到什么；有报错就贴第一条完整错误。截图请避开个人记录和凭据。

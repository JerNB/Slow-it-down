# 第二课：四个底部入口，一件件来

沿用第一课导入的 `miniapp/` 工程。这一课先学会切换页面，并走完一条本机待办的流程。保存文件后点击微信开发者工具的“编译”，先在模拟器使用虚构内容。

## 这一版能看到什么

底部四个入口：今天、一件件来、读一点、我的。底部入口写在 `miniprogram/app.json` 的 `tabBar.list` 中。“歇一会”仍可从“今天”的页面入口打开；它不是底部导航。“写给异乡的你”和“学校心理支持”从今天或我的进入。

- **今天**：保留你修改的“请记住你不是一个人”；24 条网站小事可以轮换、收藏、开始。
- **一件件来（本课重点）**：输入一件事，新增时从“先做这一件 / 先放在这里 / 接下来 / 暂时放下”四种位置中选择；也可之后用“整理”修改标题、第一小步和位置。点“先做”会把上一个“先做”移到“接下来”。完成后进入“已经做过的事”，可再放回待办。资料写入当前设备的小程序存储，正常关闭再打开仍可读取。
- **读一点**：两题选书、六本书、来源与本站译文、四则文学札记；书籍可收藏到“我的期待”。官网链接通过复制打开。
- **歇一会**：从“今天”进入，可尝试 3、5、10 分钟计时。
- **我的**：自定义期待、收藏、启动小事、心情足迹、支持入口、本机记录说明和删除。
- **心情足迹**：把原有心情记录和行动后的感受放在同一时间线里，保留发生时的当地日期。
- **学校心理支持**：输入校名，或主动授权定位后选择所在城市的学校；从 ROR 机构目录确认学校，并复制学校官网心理支持页面链接。此页需要运行查询服务；真机使用前还需部署 HTTPS 接口并配置 request 合法域名。

## 你亲手验收的顺序

1. 点击“编译”。确认底部依次显示“今天 / 一件件来 / 读一点 / 我的”，可以逐个切换。首页仍写着你改过的“请记住你不是一个人”。
2. 在“一件件来”新增四条虚构待办，每条选择不同位置。把“接下来”的一件点为“先做”，再把另一件点为“先做”；上一件应自动移到“接下来”。
3. 将“先做”的事项点为“做过了”，在“已经做过的事”中找到它，再点“放回待办”。试着用“整理”修改第一小步。
4. 正常关闭后重新打开小程序，确认四条事项、位置和完成状态仍在。不要选择“清除缓存/数据”。模拟器和手机的本地存储相互独立。

其余页面已经接入工程，可自由探索；本课先以待办闭环为验收标准。首页的“歇一会”可打开计时页，底部仍保留上述四项。

如果有白屏或点了没反应，打开微信开发者工具“调试器 → Console”，记录第一条红色报错及对应文件、行号；不要把真实日记或账号凭据发来。

## 这一课要理解的三层

| 层 | 在哪里 | 作用 |
| --- | --- | --- |
| 页面配置 | `miniprogram/app.json` | 注册页面和四个底部入口。`switchTab` 切换底部页，`navigateTo` 打开普通页面。 |
| 待办页面 | `miniprogram/pages/todo/` | `.wxml` 显示输入框和列表，`.wxss` 定义暖米白样式，`.ts` 响应选择并用 `setData` 刷新画面。 |
| 待办数据 | `miniprogram/services/space.ts` | `Task` 和 `Priority` 约束数据形状；读写 `wx.getStorageSync` / `wx.setStorageSync`，保证重新打开后可见。 |

小练习：在 `pages/todo/index.wxml` 找到“先记下来，再决定哪件值得先做。”，改成你更喜欢的一句提示，保存并编译。然后在 `pages/todo/index.wxss` 调整输入框的背景颜色，观察页面变化。

## 当前版本的边界

资料只存在本机，没有账户、云备份或网站数据导入。清除微信数据、更换设备可能丢失记录，不建议用它保存唯一一份重要日记。官网链接采用复制方式，由用户自行打开和核对。学校支持查询需要另行启动本地服务；真机需要部署 HTTPS 接口并配置小程序 request 合法域名、定位权限和隐私声明。网站的旧浏览器记录不会自动出现在小程序里。

代码检查命令：在 `miniapp/` 运行 `npm.cmd run typecheck` 和 `npm.cmd test`。它们检查类型和本机数据逻辑；页面编译与实际使用仍需要你在微信开发者工具和手机上验证。
